# Yren advertising website

Standalone static product site: features, edition comparison, setup steps, FAQ, and the supplied unchanged Windows binary. Serve this directory with `python3 -m http.server 8002 --bind 127.0.0.1` or deploy it independently to a static host.

No dependencies, external assets, analytics, checkout, or license issuance. Edition descriptions follow the supplied Rust source; CPS values are setting limits, not measured throughput guarantees. The product visual is explicitly illustrative. The supplied executable has not been run or validated on Windows.
