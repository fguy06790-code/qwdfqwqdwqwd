A few useful details.

Does Yren run in a browser?

No. Yren is a Windows desktop application. This website introduces the app and provides the supplied executable.

Will selecting an edition unlock it?

No. The desktop app verifies a genuine signed license. Website content does not change your license or feature access.

Is 1500 CPS guaranteed?

1500 CPS is the Premium setting limit in the supplied source. Actual output depends on the target application, system load, and lag guard.

Where do one-time codes redeem?

The supplied build uses a local redeem server at localhost:8787. Remote redemption requires a configured client build and compatible service.
