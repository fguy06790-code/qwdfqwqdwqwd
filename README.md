# Yren websites

Two independent websites:

- **yren-keys/** — Yren Keys demo dashboard with duration presets, access tiers, demo code batches, and browser-local history. Demo values cannot activate Yren; real signing needs a compatible secure backend.
- **yren-advertising/** — Yren product advertising site with features, edition comparison, setup instructions, FAQ, and the supplied Yren.exe download.

## Download on your computer

On this repository's GitHub page, click **Code → Download ZIP**. Extract the ZIP. Open either website folder and double-click **index.html**.

Each folder includes its own README and desktop/mobile preview images. You can host either folder separately on a static web host. Uploading this repository does not deploy the websites.

The supplied executable is unchanged and has not been run or validated on Windows. Do not put private signing keys in this repository.
